# 商品頁數據健檢 Shop Page Checkup — Claude Skill

商品上架了卻賣不好，不知道是沒人看到，還是看了不買。這個 Skill 讓 AI 看賣場後台的瀏覽數、來源和銷售數，先分清楚是哪一種問題，再給下一步；資料太少就照實說判斷不了。

## 怎麼用
- 把賣場後台的瀏覽數、流量來源、銷售數給 AI（可以截圖或複製數字）。
- AI 先判斷是「沒人看到」還是「看了不買」，每個判斷都寫依據的數字。
- 依問題給下一步；瀏覽太少時照實說資料不夠、判斷不了。
